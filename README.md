
## 📌 Project Overview

The **Daily Transactions Analysis Project** focuses on analyzing an individual’s daily financial transactions to understand spending and income patterns. The project applies **Exploratory Data Analysis (EDA)** techniques to extract meaningful insights that can help in budgeting, expense tracking, and financial planning.

---

## 🎯 Objectives

* Analyze daily income and expense transactions
* Identify major spending categories and payment modes
* Study income vs expense behavior
* Observe daily and monthly transaction trends

---

## 🛠 Tools & Technologies

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / VS Code

---

## 📂 Dataset Description

The dataset contains dummy daily transaction records with the following columns:
Dataset: https://github.com/AryaaAKr/Daily_Transaction/blob/main/Daily%20Household%20Transactions.csv

* **Date:** Date and time of transaction
* **Mode:** Payment mode (Cash, Bank, Card, etc.)
* **Category:** Transaction category
* **Subcategory:** Detailed transaction type
* **Note:** Description of transaction
* **Amount:** Transaction amount
* **Income/Expense:** Type of transaction
* **Currency:** INR

---

## 🔄 Project Workflow

1. Data Loading and Inspection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Visualization of spending patterns
5. Time-series trend analysis
6. Insight generation

---

## 📈 Key Analysis & Visualizations

* Distribution of transaction amounts
* Category-wise and subcategory-wise spending
* Income vs Expense comparison
* Preferred payment modes
* Daily and monthly transaction trends
* Correlation analysis between categories

---

## 🔍 Key Insights

* Most transactions are clustered around lower amounts
* Food and transportation are major expense categories
* Cash and bank transfers are the most used payment modes
* Monthly trends show variations in spending behavior
